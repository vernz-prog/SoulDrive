# Печатная плата SoulDrive (макет)

100×70 мм, 2 слоя. Картинки: `pcb_top.png` (верх), `pcb_bottom.png` (низ, вид снизу),
`pcb_assembly.png` (в сборе). Генерируются `tools/gen_pcb.py` из той же таблицы
соединений (`tools/sd_design.py`), что и принципиальная схема.

Трассировка сделана простым сеточным трассировщиком: все цепи разведены, масса —
полигоны на обоих слоях. Это макет для согласования размещения, а не файлы для
производства: перед заказом перенесите плату в KiCad/EasyEDA, пройдите DRC и
сверьте посадочные места ESP32 DevKitC (ряды 25,4 мм) и клеммника X1 (шаг 3,81)
с купленными деталями.
