# Калибровка SoulDrive

Все константы лежат в [`firmware/src/config.h`](../firmware/src/config.h). После
каждого изменения перепрошейте плату: `pio run -t upload`.

Отладочные данные идут в USB-Serial (115200 бод) в виде JSON. Смотреть их можно
так: `pio device monitor`.

## Скорость: `SPEED_PULSES_PER_KM`

1. Включите GPS-спидометр на телефоне.
2. Держите ровно 60 км/ч по GPS и запишите показания SoulDrive.
3. Новое значение = `старое × показание_SoulDrive / 60`.

Второй способ — по километровым столбам. Проедьте 1 км по GPS-трекеру и посчитайте
импульсы. В Serial смотрите, как растёт `odo`.

## Топливо: `FUEL_TABLE`

Значения в таблице типовые для датчика 2108-3827010. Чтобы откалибровать:

1. Слейте бак до лампы резерва.
2. Заливайте по 5 л из канистры и после каждой порции записывайте сопротивление
   датчика. Его можно измерить мультиметром на снятом проводе или пересчитать из
   напряжения на GPIO34: `R = 100 × U / (3,3 − U)`.
3. Впишите пары «сопротивление → литры» в `FUEL_TABLE` по убыванию сопротивления.

## Температура ОЖ: `CLT_TABLE`

Таблица для ТМ-106 тоже типовая. Проверка: снятый датчик опускают в воду вместе
с кухонным термометром, нагревают и записывают сопротивление при 40, 60, 80, 90 и 100 °C.

## Обороты: `SPARKS_PER_REV`

Для 4-цилиндрового двигателя это 2. Если тахометр показывает ровно вдвое больше
или меньше, проверьте, откуда взят сигнал.
